# Datacendia Core v0.2.2-alpha -- Cryptographic Service Frontend UIs

> **Pre-release.** This is an alpha release for early testing and feedback.

## Highlights

**8 Cryptographic Service Frontend UIs** — user-facing interfaces for Datacendia's forensic-grade, independently verifiable, cryptographically signed decision infrastructure. Every crypto primitive now has a dedicated React component or full page.

## New Pages

### CendiaVerify™ — Public Verification Portal (`/verify`)
No-auth public page where regulators, auditors, or third parties can paste a Regulator's Receipt JSON and verify all cryptographic claims step-by-step: Ed25519 signature, ML-DSA-65 post-quantum signature, Merkle root integrity, RFC 3161 timestamp, and VDF time-lock proof. Includes CLI verification instructions.

### CendiaGapScan™ — Compliance Gap Scanner (`/cortex/compliance/gap-scanner`)
Dashboard analyzing compliance gaps across 8 regulatory frameworks: EU AI Act, NIST AI RMF, ISO 42001, GDPR, HIPAA, SOX, SR 11-7, and Basel III/IV. Filterable by framework and severity with summary cards showing critical/high/medium/low counts.

### CendiaEscrow™ — Shamir Share Management (`/cortex/crypto/escrow`)
Full management page for Shamir Secret Sharing (3-of-5 threshold default). Create escrows for sealed decisions, manage shareholders, submit shares for reconstruction, and view VDF time-lock and AES-256-GCM encryption metadata.

## New Components

### CendiaEvidence™ — Evidence Package Download
Reusable panel for downloading evidence packages in three formats:
- **ZIP** — Full evidence bundle via backend API
- **Standalone HTML** — Self-contained offline verifier with embedded receipt data and Ed25519 verification logic
- **JSON** — Raw receipt data for programmatic consumption

Integrated into the Regulator's Receipt page.

### CendiaStamp™ — Cryptographic Seal SVG
SVG seal renderer that fetches from backend API (`/api/v1/verify/stamp/:hash`) or renders a client-side fallback displaying receipt hash (truncated), verification date, and Ed25519 + ML-DSA-65 dual-signature badge. Three sizes (sm/md/lg). Integrated into the Regulator's Receipt page.

### CendiaPrecedent™ — Similar Decisions Panel
TF-IDF precedent matching panel showing the top 5 similar past decisions with similarity scores, outcomes, key differences, and cross-deliberation insights. Expandable detail rows. Integrated into the Post-Deliberation Panel.

### CendiaRedTeam™ — Red Team Report Panel
6-vector adversarial analysis report covering prompt injection, data poisoning, model extraction, membership inference, evasion attacks, and supply chain compromise. Shows gate decision (PASS/CONDITIONAL/FAIL), overall risk score, and expandable attack vector details with severity badges. Integrated into the Post-Deliberation Panel.

### CendiaReplay™ — Decision Replay Theater
*Already existed (611 lines).* Confirmed complete — full deliberation playback with timeline scrubbing, agent frame highlighting, play/pause controls, and speed adjustment. Routed at `/cortex/council/replay-theater`.
