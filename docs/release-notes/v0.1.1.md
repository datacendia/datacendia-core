# Datacendia Core v0.1.1 -- Open-Source Hygiene

## Added

- **ARCHITECTURE.md** -- Full system architecture overview for contributors
- **CODEOWNERS** -- Team-based code ownership for PR reviews
- **Issue & PR templates** -- Standardized bug reports, feature requests, and PR checklists
- **Docker build workflow** -- `.github/workflows/docker.yml` for Docker Hub image publishing
- **Standards & Governance section** in README linking to DDGI framework repo

## Changed

- **Copyright headers** -- Replaced "Proprietary and confidential" with Apache 2.0 across 913 source files
- **JSDoc documentation** -- Module-level headers added to all 932 source files
- **CI workflow** -- Postgres 16 + Redis 7 Docker services for integration tests

## Removed

- Enterprise-only page components, services, routes, and test suite from community edition
- Broken `test:mutation` npm script

## Fixed

- UTF-8 encoding corruption in 6 markdown files
- NVIDIA badge rendering on GitHub
- 5 broken navigation anchor links
- Package renamed from `datacendia-components` to `datacendia-core`
