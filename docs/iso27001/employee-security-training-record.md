## Module Coverage

All employees must complete the following modules:

| Module | Duration | Topics | Required For |
|---|---|---|---|
| 1. Information Security Fundamentals | 20 min | CIA triad; asset classification; acceptable use | All |
| 2. Password & Authentication Security | 15 min | Strong passwords; MFA; phishing resistance; JWT security | All |
| 3. Phishing Awareness | 20 min | Recognising phishing; reporting suspicious emails; spearphishing | All |
| 4. Data Handling & Classification | 20 min | Data categories; handling rules; clean desk; screen lock | All |
| 5. Incident Reporting | 15 min | What to report; how to report; escalation path | All |
| 6. GDPR / Privacy Awareness | 20 min | Personal data; data subject rights; breach notification; your obligations | All |
| 7. AI Ethics & Regulatory Compliance | 20 min | EU AI Act; CO SB 205; prohibited AI practices; bias awareness | Engineering |
| 8. Secure Development | 30 min | OWASP Top 10; parameterised queries; input validation; secrets management | Engineering |
| 9. Supplier & Third-Party Security | 15 min | Vendor due diligence; DPA obligations; supply chain risk | All |
| **Quiz** | 20 min | Covering all modules | All |
