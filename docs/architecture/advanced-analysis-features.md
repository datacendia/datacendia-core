## 3. Ghost Board Sequence

```mermaid
sequenceDiagram
    participant User
    participant GB as GhostBoardService
    participant AI as InferenceService
    participant DB as PostgreSQL

    User->>GB: submitProposal(title, content, boardType, difficulty)

    GB->>GB: selectBoardMembers(boardType)
    GB->>GB: generateBoardComposition()

    loop Each Board Member
        GB->>AI: generateQuestions(memberPersona, proposal)
        AI-->>GB: Member-specific challenges
    end

    GB->>GB: buildSessionTranscript()
    GB->>GB: calculatePreparednessScore()
    GB->>GB: identifyGaps()
    GB->>GB: identifyStrengths()

    GB->>DB: persist ghost_board_sessions
    GB-->>User: GhostBoardResult
    Note over GB,User: Board members, questions,<br/>scores, gaps, recommendations
```

## 5. Chronos AI Analysis Flow

```mermaid
sequenceDiagram
    participant User
    participant API as decision-intel.ts
    participant CS as ChronosAIService
    participant AI as InferenceService
    participant DB as PostgreSQL

    User->>API: POST /chronos/ai/pivotal-moments
    API->>CS: detectPivotalMoments(events, limit)
    CS->>AI: Analyze event stream for inflection points
    AI-->>CS: Identified pivotal moments with confidence
    CS-->>API: {moments: [...], confidenceScores: [...]}
    API-->>User: Pivotal moments report

    User->>API: POST /chronos/ai/causal-chain
    API->>CS: analyzeCausalChain(rootEvent, allEvents)
    CS->>AI: Trace causality through event network
    AI-->>CS: Causal link graph
    CS-->>API: {causalLinks: [...], rootCauses: [...]}
    API-->>User: Causal chain analysis

    User->>API: POST /chronos/ai/what-if
    API->>CS: analyzeWhatIf(event, alternativeAction)
    CS->>AI: Counterfactual simulation
    AI-->>CS: Projected outcome differences
    CS-->>API: {alternativeOutcome: {...}, riskDelta: ...}
    API-->>User: What-if analysis
```
