## ¿Qué es CendiaGateway?

CendiaGateway es un proxy inverso que se ubica entre cada empleado de su organización y cada modelo de inteligencia artificial que utilicen — ChatGPT, Copilot, Gemini, modelos internos, cualquier sistema de IA. Desde el primer día de despliegue, genera registros criptográficamente firmados de cada interacción.

**Despliegue en 30 minutos** mediante un cambio de DNS. Sin software en dispositivos de usuarios. Sin cambio en flujos de trabajo existentes.

---

## ¿Qué hace?

| Función | Descripción |
|---------|-------------|
| **Escaneo PII** | Detecta y bloquea datos personales (nombres, DNI, cuentas bancarias, datos de salud) antes de que lleguen al modelo de IA |
| **Motor de Políticas** | Aplica las políticas de gobernanza IA de su organización en tiempo real — qué modelos se pueden usar, qué datos se pueden enviar, qué está prohibido |
| **Firma Criptográfica** | Cada interacción se firma con Ed25519 y se registra con hash SHA-256, creando un registro inmutable imposible de modificar retroactivamente |
| **Detección de Shadow AI** | Identifica uso no autorizado de herramientas de IA por empleados |
| **Paquete de Evidencia** | Genera documentación lista para presentar a reguladores — el tipo de registro que DS 115-2025-PCM e ISO/IEC 42001 requieren |

---

## Tres Capas de Cobertura

### Capa 1: Gateway API (Proxy Inverso)
Intercepta todas las llamadas API a proveedores de IA. Compatible con OpenAI, Anthropic, Google AI, Azure OpenAI, Mistral, Cohere, Groq y Ollama.

### Capa 2: Extensiones de Navegador
Monitorea 15+ sitios web de IA incluyendo ChatGPT, Claude, Gemini, Copilot, Perplexity y DeepSeek. Chrome/Edge/Brave (Manifest V3), Firefox (Manifest V2), Safari. Desplegable vía Group Policy o MDM.

### Capa 3: Proxy HTTP de Red
Interceptación a nivel de red mediante archivo PAC. Independiente del navegador, funciona con cualquier aplicación.

## ¿Qué regulaciones aborda?

- **DS N° 115-2025-PCM** — Estándar peruano que adopta ISO/IEC 42001:2023 para gobernanza de IA
- **ISO/IEC 42001:2023** — Sistemas de Gestión de Inteligencia Artificial
- **Ley 31814** — Ley orgánica de IA del Perú (sistemas de IA de alto riesgo)
- **Regulación SBS** — Gobierno corporativo y gestión integral de riesgos
- **EU AI Act** — Artículo 12 (documentación técnica y trazabilidad)
- **GDPR** — Artículo 22 (decisiones automatizadas)
