# Pitch Deck Screenshots

Screenshots of the Datacendia platform for use in investor and sales pitch decks.

## How to Capture

1. Start **datacendia-core** on `http://localhost:5174` (no backend needed — fallback data populates all pages)
2. Start **datacendia-components** on `http://localhost:5175` (no backend needed — fallback data populates all pages)
3. Use browser at **1920×1080** resolution, dark mode
4. Capture each page using the URLs below
5. Save as PNG with the filenames listed
