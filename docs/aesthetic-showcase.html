Decision Time Travel

#1
Decision Wormhole Portal
Animated concentric rings pulling you into a past decision. Orbiting particles, pulsing rings, click to enter. Canvas-rendered with physics.
#2
Decision Diff Viewer
Side-by-side old vs new with animated highlights. Red lines fade out, green fade in. Changes ripple like a code review.
#3
Temporal Risk Heatmap
GitHub-contribution-style grid. Each cell = a decision, color = risk. Staggered fade-in animation. Hover for tooltips.
#4
Archaeology Dig Layers
Time epochs as animated sediment layers. Deeper = older. Each layer undulates with sine waves. Scroll to dig through history.
#5
Replay Scrubber + Emotion Arcs
Video-style timeline with agent emotion waves stacked. Scrub marker auto-advances. Each agent = different color wave.
#6
Decision Constellation Map
Stars connected by faint lines. Each star = a decision. Mouse parallax shifts the field. Brightness = impact level.
#7
Butterfly Cascade Tree
Branching probability paths from one decision. Gold path = chosen outcome. Gray = alternatives that faded. Fractal recursion.
#8
Decision Fossil Archive
Sealed decisions as fossils. Hover to brush away dust particles, revealing preserved data beneath. Mouse-driven reveal.
