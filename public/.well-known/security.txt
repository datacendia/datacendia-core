# =============================================================================
# SCOPE
# =============================================================================
#
# In-scope assets:
#   - app.datacendia.com (Production SaaS platform)
#   - api.datacendia.com (API endpoints)
#   - *.datacendia.com (all subdomains)
#   - datacendia/datacendia-core (GitHub — open-source components only)
#
# Out-of-scope:
#   - Physical security attacks
#   - Social engineering / phishing of Datacendia employees
#   - Denial of Service (DoS / DDoS) attacks
#   - Attacks requiring physical access to Datacendia systems
#   - Third-party services not under Datacendia's direct control
#   - Vulnerabilities in dependencies without a demonstrated exploit path
#   - Self-XSS or issues only exploitable by the authenticated user themselves
#
# =============================================================================
# DISCLOSURE PROCESS
# =============================================================================
#
# 1. EMAIL  — security@datacendia.com (PGP-encrypted preferred)
#    Subject line: [SECURITY] <brief description>
#    Include: description, reproduction steps, impact assessment, CVE/CWE if known
#
# 2. RESPONSE TIMELINE:
#    - Acknowledgment: within 48 hours of receipt
#    - Initial triage and severity assessment: within 5 business days
#    - Remediation timeline communicated: within 10 business days
#    - Patch released (CVSS 9.0+): within 15 business days
#    - Patch released (CVSS 7.0–8.9): within 30 business days
#    - Patch released (CVSS < 7.0): within 90 business days
#    - Public disclosure: coordinated with reporter (default 90-day window)
#
# 3. SEVERITY CLASSIFICATION (CVSS v3.1):
#    CRITICAL (9.0–10.0) — Immediate escalation to CISO + CTO
#    HIGH     (7.0–8.9)  — Security team response within 24 hours
#    MEDIUM   (4.0–6.9)  — Standard remediation queue
#    LOW      (0.1–3.9)  — Next scheduled security release
#
# =============================================================================
# SAFE HARBOR
# =============================================================================
#
# Datacendia, LLC will not pursue civil or criminal legal action against
# security researchers who:
#
#   (a) Report vulnerabilities through this policy in good faith
#   (b) Do not access, modify, or delete customer data beyond what is
#       strictly necessary to demonstrate the vulnerability
#   (c) Do not exploit the vulnerability for profit or competitive advantage
#   (d) Do not disclose vulnerability details publicly before Datacendia
#       has had reasonable opportunity to remediate (90 days)
#   (e) Do not conduct Denial of Service attacks or disrupt service availability
#
# Good-faith security research is protected and valued by Datacendia.
#
# =============================================================================
# RECOGNITION & BUG BOUNTY
# =============================================================================
#
# Researchers who responsibly disclose valid security vulnerabilities will
# receive:
#   - Public acknowledgment on our Hall of Fame (with permission)
#   - Written confirmation suitable for resume / portfolio use
#   - Monetary rewards for CVSS 7.0+ vulnerabilities (case-by-case basis)
#     Contact security@datacendia.com for bounty details
